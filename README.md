# CASEFILE

An AI-powered detective game. Players interrogate LLM-driven suspects, uncover evidence and solve a mystery. A deterministic game engine controls the truth of the mystery, not the model.

Status: Milestone 1 (case design) is done. Milestone 2 (backend engine) is in progress. See [docs/design/README.md](docs/design/README.md) for the milestone plan and [backend/README.md](backend/README.md) to run the code. To play CASE #001 in the terminal with the mock AI: `cd backend && uv run casefile`.
